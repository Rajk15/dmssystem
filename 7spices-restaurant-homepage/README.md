# 7 Spices Restaurant Homepage

Premium restaurant-style front page for `https://saasmarket.pro/staging/`.

## Behaviour

- Replaces **only** the WordPress front page via `template_include`
- Pulls live WooCommerce categories and dishes (no invented menu items)
- Links Order Now / View Menu to the existing shop; Cart and Contact use existing pages
- Designed for **7 Spices Authentic Indian Restaurant and Bar** (not a SaaS marketplace)

## Install

1. Upload `7spices-restaurant-homepage.zip`
2. Activate **7 Spices Restaurant Homepage**
3. Deactivate **SaaSMarket Pro Homepage** if it is still active

## Rollback

Deactivate this plugin to restore the previous front-page renderer.
