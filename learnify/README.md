# Learnify Dashboards

Shared LMS dashboard UI matching the attached Learnify design system for **Student**, **Trainer**, and **Admin** roles.

## Features

- Blue sidebar shell, rounded cards, hero banner, stats, calendar, and progress chart
- Role switcher in the top bar to flip between Student / Trainer / Admin
- Working navigation for each role (courses, live classes, assignments, messages, etc.)
- Interactive search, reminders, join live, resume lesson, settings save, and toast feedback

## Run

```bash
cd learnify
npm install
npm run dev
```

Open the printed local URL (default `http://127.0.0.1:5173`).
