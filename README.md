# EyzaKart Lenses — WooCommerce SPH Pricing

Custom WordPress plugin that doubles the Aqualens 24Hrs NXT Monthly Disposable selling price when OD and OS SPH values differ.

See [docs/EYE-SPH-PRICING.md](docs/EYE-SPH-PRICING.md) for inspection notes and [eyza-eye-sph-pricing/](eyza-eye-sph-pricing/) for the installable plugin.

## Quick install

1. Upload `eyza-eye-sph-pricing.zip` via **Plugins → Add New → Upload Plugin**, or unzip into `wp-content/plugins/`.
2. Activate **Eyza Eye SPH Conditional Pricing**.
3. Test product https://lenses.eyzakart.com/product/aqualens-24hrs-nxt-monthly-disposable/
