# Eyzakart Lenses

Modern marketing site for [Eyzakart](https://lenses.eyzakart.com/) — premium power and coloured contact lenses.

Product and category links open the live WooCommerce store for checkout.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
